# نظام أبو ليث ERP

نظام محاسبي وإداري ومخزني وإنتاجي متكامل لمعمل أبو ليث لإنتاج الكيك والنواشف.

---

## 📋 المميزات

- ✅ يعمل بدون إنترنت (Offline First)
- ✅ مزامنة تلقائية عند توفر الإنترنت
- ✅ تطبيقات مستقلة حسب صلاحيات المستخدمين
- ✅ إدارة الإنتاج والمخزون والمعرض والموزعين
- ✅ تقارير شاملة وكشف مقارنة
- ✅ واجهة عربية بالكامل RTL

---

## 👥 المستخدمون

| المستخدم | الصلاحيات |
|----------|-----------|
| المدير العام | جميع الصلاحيات |
| مدير الإنتاج | خطة الإنتاج، تسجيل الإنتاج، كشف المقارنة، سجل الإنتاج، إحصائيات |
| مدير المخزن | مخزن الإنتاج، المواد الخام، التحويل للمعرض، الجرد |
| مدير المعرض | مخزون المعرض، المبيعات، كشف الحساب، التوريد للخزنة |
| مدير الخزنة | الخزنة، المصروفات، حسابات العمال، حسابات الموردين |
| مدير الموزعين | قائمة الموزعين، التحميل، المرتجعات، التصفية |

---

## 🛠️ التقنيات المستخدمة

- **Flutter** - تطبيقات الهاتف
- **SQLite** - قاعدة بيانات محلية
- **Node.js + Express** - الخادم المركزي
- **SQLite** - قاعدة بيانات الخادم
